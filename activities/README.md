# Mastering Articulate Storyline 360 for e-Learning Content Creation — Activities

**Course code:** TGS-2024042308
**Version:** v11 · 17 October 2026

The 14 activities form one connected workplace-safety build. Start from a blank Storyline project in Activity 01, save the exact named checkpoint after every activity, and continue from that checkpoint. No completed .story solution is supplied because Storyline cannot be authored or validated on this macOS build host.

## Activity sequence

1. [Activity 01 — Start the Safety Module and Storyboard](activity-01-brief-storyboard-project/README.md) — Create the local source baseline, five-scene architecture and traceable storyboard.
2. [Activity 02 — Build Theme, Masters and Menu](activity-02-theme-masters-menu/README.md) — Create reusable visual layouts and accessible scene navigation.
3. [Activity 03 — Add Media and Hazard Scene](activity-03-media-hazard-scene/README.md) — Construct the warehouse visual with rights-aware media and seven meaningful hazards.
4. [Activity 04 — Add Layers, States, Variables and Gate](activity-04-layers-states-gating/README.md) — Make hazard discovery accessible, persistent and completion-gated.
5. [Activity 05 — Build Motion, Slider and Dial Controls](activity-05-motion-slider-dial/README.md) — Use motion and data controls to explain dynamic workplace risk.
6. [Activity 06 — Create View, Try and Test Simulations](activity-06-screen-recording-simulation/README.md) — Capture and deploy the supplied incident-report simulation in three Storyline modes.
7. [Activity 07 — Add Audio, Captions and Accessibility](activity-07-audio-captions-accessibility/README.md) — Add the supplied eight-scene HarbourLink annual WSH narration with one matching MP3/VTT pair per screen, equivalent transcript and keyboard-operable Replay/Stop controls.
8. [Activity 08 — Build Branching and Freeform Decisions](activity-08-branching-freeform/README.md) — Create consequence-based decisions and an accessible freeform interaction.
9. [Activity 09 — Build the Safety Question Bank and Quiz](activity-09-question-bank-quiz/README.md) — Create a five-question graded quiz with controlled bank coverage and 80% pass.
10. [Activity 10 — Configure Results, Retry and Completion](activity-10-results-retry-completion/README.md) — Track only the scored quiz, set 80% pass and prove retry/review behaviour.
11. [Activity 11 — Configure Player, Translation and Review 360](activity-11-player-translation-review/README.md) — Prepare the module for accessible review and localisation.
12. [Activity 12 — Publish and Test SCORM 1.2 and 2004](activity-12-scorm-publishing-testing/README.md) — Create root-correct SCORM packages and verify runtime behaviour in a sandbox.
13. [Activity 13 — Publish Tin Can xAPI and Validate Release](activity-13-xapi-release-validation/README.md) — Prepare an xAPI package without embedded secrets and complete regression evidence.
14. [Activity 14 — Independent Mini Capstone](activity-14-independent-mini-capstone/README.md) — Independently create a small original e-learning module from a new blank project and present verified evidence.
