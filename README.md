## About the course

This hands-on programme develops the judgement and Storyline 360 authoring skills needed to turn a verified performance need into a coherent storyboard, accessible media, meaningful interaction, reliable assessment logic and governed delivery. Version v10 adds ebook-informed guidance on performance-gap analysis, prototyping, visual design grammar, video production, accessible media equivalence, learner-controlled discovery and real-device testing.

## Learning outcomes

- Conceptualise and map digital storyboards that integrate purposeful storytelling.
- Identify audience-fit e-learning content, formats, styles and accessibility requirements.
- Determine effective modes and processes for distributing interactive content.
- Develop execution guidelines and a defensible content-delivery frequency.

## Topics covered

1. Get started: performance gap, storyboard, prototype, project model, interface, scenes, slides, quizzes and libraries.
2. Work with assets: visual grammar, pictures, 360° media, video, audio, captions, media equivalents and screen recordings.
3. Build interactivity: meaningful choices, triggers, states, variables, branching, feedback and interaction QA.
4. Present, review and distribute: themes, player, multi-device UX, accessibility, Review 360, publishing, LMS/LRS tracking and lifecycle governance.
