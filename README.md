# Mastering Articulate Storyline 360 for e-Learning Content Creation

WSQ courseware for **TGS-2024042308**, developed by Tertiary Infotech Academy Pte Ltd.

The package is a four-day, 32-hour programme covering digital storyboarding, audience-fit media, accessible interaction, quiz and result logic, Review 360, and controlled LMS/LRS publishing.

## Courseware

- `courseware/Mastering Articulate Storyline 360 for e-Learning Content Creation-v9.pptx` — editable trainer deck with native PowerPoint charts
- `courseware/Mastering Articulate Storyline 360 for e-Learning Content Creation-v9.pdf` — learner slides
- `courseware/LG-*.docx` and `.pdf` — detailed Learner Guide
- `courseware/LP-*.docx` and `.pdf` — four-day Lesson Plan aligned to the deck
- `LEARNER-GUIDE.md` — accessible Markdown edition of the Learner Guide

The slides are concept-led and visual. Detailed click-by-click procedures are deliberately kept in the Learner Guide and lab guides.

## Storyline labs

Each folder in `labs/` is self-contained and includes:

- a detailed Markdown guide and matching PDF;
- the original Articulate Storyline `BEGIN.story` file;
- the corresponding completed `END.story` reference;
- a visual project preview.

| Lab | Application |
|---|---|
| 01 | Replace visuals and establish a theme |
| 02 | Populate storyboard content |
| 03 | Curate and replace audience-fit media |
| 04 | Create and govern an AI-assisted visual variation |
| 05 | Add narration and closed captions |
| 06 | Build a multi-slide audio and caption system |
| 07 | Build a graded question with feedback |
| 08 | Build a multi-question quiz and result logic |
| 09 | Review, summarise and prepare a controlled publish |
